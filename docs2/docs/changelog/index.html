1.5.4

2018-12-31

本次更新的摘要说明，请看这里

  • :sparkles: 新增 地球每刻；

    地球每刻的照片均来自 向日葵-8號 ，由于不愿过多消耗向日葵-8號的带宽，通过简 Tab 访问并获取到的地球照片均来在于自建的服务，每小时更新一次。

  • :sparkles: 新增 背景自动更新

  • :sparkles: 新增 历史记录

  • :sparkles: 新增 探索

    背景管理器增加了新的 Tab - 探索，通过它可以随机显示来自 自定义Unsplash 的精美壁纸。

  • :sparkles: 新增 白噪音

    得益于 背景自动播放 与 地球每刻 功能，现在你可以在新标签页停留更多的时间，播放白噪音就是一个非常不错的方案。目前内置了：咖啡馆、爵士乐、下雨天、雷声 四种音效，未来会加入更多音源。

  • :sparkles: 新增 发送到手机

    借助 JSBox 可以将新标签页中的背景发送到手机端（ iOS 设备）上了。

  • :lipstick: 优化了下载背景到本地 的算法；

  • :lipstick: 优化了 选项卡 界面布局；

  • :memo: 截至到目前全部的功能
