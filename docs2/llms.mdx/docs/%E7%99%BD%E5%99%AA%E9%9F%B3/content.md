# 白噪音 (/docs/%E7%99%BD%E5%99%AA%E9%9F%B3)



> 此功能最低要求 1.5.4 版本，如低于此版本，[请升级](http://ksria.com/simptab/) 到最新版本。

## 含义 [#含义]

得益于 1.5.4 增加了 [背景自动播放](多种背景源#背景自动播放) 与 [地球每刻](多种背景源#地球每刻) 功能，现在你可以在新标签页停留更多的时间，播放白噪音就是一个非常不错的方案。

## 开启/关闭 [#开启关闭]

* 仅支持快捷键 <kbd>w</kbd> 进入；
* 在界面上无任何进入标识；
* 支持 ESC 隐藏；

## 说明 [#说明]

* 目前内置了 `咖啡馆` `爵士乐` `下雨天` `雷声` 四种白噪音，可同时叠加使用；
* 未来会加入更多的白噪音；
* 白噪音提供的 MP3 均为免费使用的音源，同时放在了自建的 腾讯云 上；
* 可同时更改不同 BGM 的音量大小；
* 同时支持 「图片模式」和 [禅模式](禅模式) 。
