# 快捷键 (/%E5%BF%AB%E6%8D%B7%E9%94%AE)



> 简 Tab 为了让新标签页呈现  **极致美景**，所以隐藏了绝大多数的操作界面，但这些操作界面均支持快捷键。

![Q9DHbt.png](https://res.cloudinary.com/simpread/image/upload/v1789968796/simptab/simptab/13b6bc97de29cf245b039fd203fb107d.png)

> 请记住两个最重要的快捷键

<kbd>?</kbd>

在界面的任意位置，输入 <kbd>?</kbd> 即可呼出，其中包含了简 Tab 全部的快捷键指令。

<kbd>esc</kbd>

绝大多数的界面/功能，均支持通过 <kbd>esc</kbd> 退出。
